# Gray's Investment Lab

A local learning app for coding, AI tools, and investment thinking.

The goal is not automated trading. The goal is to build tools that help with research, tracking, journalling, and learning.

## First Features

- Watchlist for companies and ETFs
- Pretend portfolio simulator
- Dashboard for simple returns
- Journal for lessons learned

## Run Locally

Install Node.js LTS first, then run:

```powershell
npm install
npm run dev
```
